# cron

Cron 是 Linux/Unix 下最常用的定时任务工具。本机 crontab 的语法分两块：`时间表达式` + `要执行的命令`。

## 核心公式

```
*    *    *    *    *    Command
┬    ┬    ┬    ┬    ┬    ┬
│    │    │    │    │    │
│    │    │    │    │    └── 执行的命令（尽量写绝对路径）
│    │    │    │    └─────── 星期几 (0–7，0 和 7 都是周日)
│    │    │    └──────────── 月份 (1–12)
│    │    └───────────────── 日期 (1–31)
│    └────────────────────── 小时 (0–23)
└─────────────────────────── 分钟 (0–59)
```

本机用 `crontab -e` 编辑。时区跟 **机器时区** 走，不是 UTC。

**坑**：日期和星期都写了具体值时，多数 Linux crontab（Vixie）是 **或**，不是同时满足。比如 `0 0 1 * 1` 表示「每月 1 号，**或者** 每周一」，不是「周一且是 1 号」。只想按星期就，日期位留 `*`；只想按日期就，星期位留 `*`。

---

## 四个常用特殊符号

**`*`**：这一位上任意值，口语就是「每」。时位是 `*`，每个小时都会轮到（还要看其它位）。

**`,`**：列举。比如 `1,3,5` 表示第 1、3、5 分钟。

**`-`**：范围。比如 `1-5` 表示第 1 到第 5 分钟。

**`/n`**：步长，每隔 n。比如 `*/10` 表示每隔 10 分钟。

## 例子

| 需求 | Cron 写法 | 解读 |
| --- | --- | --- |
| 每分钟执行 | `* * * * *` | 五个星号全开 |
| 每天凌晨 2:30 执行 | `30 2 * * *` | 分钟 30，小时 2，其余任意 |
| 每周一上午 9:00 执行 | `0 9 * * 1` | 0 是周日，1 是周一 |
| 每月 1 号午夜 0:00 执行 | `0 0 1 * *` | 日期填 1，星期位保持 `*` |
| 每隔 5 分钟执行 | `*/5 * * * *` | 分钟位用步长 |
| 每隔 2 小时执行 | `0 */2 * * *` | 小时位用步长，分钟归零，不然整点那一小时里每分钟都跑 |
| 工作日下午 6 点（18:00）执行 | `0 18 * * 1-5` | 星期用范围 1–5（周一到周五） |
| 每天凌晨 2:15 和 2:45 执行 | `15,45 2 * * *` | 分钟用逗号列举 |

## 小问题

如果说我要每天早上 8:20 和每天晚上 9:40 执行该怎么写呢？

答案：直接写 2 条规则吧！！！

```
20 8 * * *  /path/to/script
40 21 * * * /path/to/script
```
