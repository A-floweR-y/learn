# cron

Cron 是 Linux/Unix 下最常用的定时任务工具。它的语法分为两大部分：`时间表达式` + `要执行的命令`。

## 核心公式

```cron
*    *    *    *    *    Command
┬    ┬    ┬    ┬    ┬    ┬
│    │    │    │    │    │
│    │    │    │    │    └── 执行的命令（绝对路径或脚本）
│    │    │    │    └─────── 星期几 (0 - 7) [0和7都代表周日]
│    │    │    └──────────── 月份 (1 - 12)
│    │    └───────────────── 日期 (1 - 31)
│    └────────────────────── 小时 (0 - 23)
└─────────────────────────── 分钟 (0 - 59)
```

## 四个常用特殊符号

**`*`**：代表任意值，表示 `每`。比如在 “时” 位是 `*`，代表每小时。

**`,`**：代表列举。比如 `1,3,5` 表示第 `1、3、5` 分钟。

**`-`**：代表范围。比如 `1-5` 表示第1到第5分钟。

**`/n`**：代表步长或者每隔。比如 `*/10` 表示每隔10分钟。

## 例子

| 需求 | Cron 写法 | 解读 |
| --- | --- | --- |
| 每分钟执行 | `* * * * *` | 五个星号全开 |
| 每天凌晨 2:30 执行 | `30 2 * * *` | 分钟 30，小时 2，日期、月份、星期都是任意 |
| 每周一上午 9:00 执行 | `0 9 * * 1` | 注意：0 代表周日，1 代表周一 |
| 每月 1 号午夜 0:00 执行 | `0 0 1 * *` | 日期填 1，月份任意 |
| 每隔 5 分钟执行 | `*/5 * * * *` | 分钟位用步长 |
| 每隔 2 小时执行 | `0 */2 * * *` | 小时位用步长，分钟归零防止堆叠 |
| 工作日下午 6 点（18:00）执行 | `0 18 * * 1-5` | 星期用范围 1-5（周一到周五） |
| 每天凌晨 2:15 和 2:45 执行 | `15,45 2 * * *` | 分钟用逗号列举 |
