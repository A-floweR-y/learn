# Vim

## 模式

Vim 有两种你必须分清的状态：

- **普通模式**：刚打开就是这个。按键是命令，不是打字。
- **插入模式**：现在才是在写内容。

`i` 进入插入，`Esc` 回到普通。卡住了，先狂按几下 `Esc`。

## 进去、改、出来

```
vim /etc/nginx/nginx.conf
```

有的机器只有 `vi`，用法一样。

| 你想做的事 | 先回到普通模式，再 |
| --- | --- |
| 保存 | `:w` |
| 退出 | `:q` |
| 保存并退出 | `:wq` 或 `ZZ` |
| 不保存，强制退出 | `:q!` |

出不去，几乎都是还在插入模式，或者改过却用了 `:q`。`Esc`，然后 `:wq` 或 `:q!`。

## 移动、搜索

方向键一般能用。没有方向键时：`h` `j` `k` `l` 是左下上右。

| 动作 | 按键 |
| --- | --- |
| 文件开头 / 结尾 | `gg` / `G` |
| 跳到第 42 行 | `:42` |
| 搜 | `/关键字` 回车，`n` 下一个，`N` 上一个 |
| 显示行号 | `:set nu` |

改 Nginx 时，先 `/server_name` 或 `/listen`，比对着滚更快。

## 改几个字

都在普通模式下：

| 动作 | 按键 |
| --- | --- |
| 删当前字符 | `x` |
| 删整行 | `dd` |
| 复制整行 / 粘贴 | `yy` / `p` |
| 撤销 | `u` |
| 从光标改到词尾 | `cw`，改完 `Esc` |

要改一块：`v` 进入可视，移动选中，`d` 删或 `c` 改。

## 小坑

从终端贴一大段配置进来，缩进经常乱飞。先 `Esc`，`:set paste`，再 `i` 粘贴。贴完 `:set nopaste`。

不要在服务器上配插件、同步一份花哨的 `.vimrc`。下一台机器没有这些，手会生。
