# vim

`vim` 是基于终端的模式编辑器，可以打开 1 个或者多个文件。

最常用的命令：

```bash
vim nginx.conf        # 打开文件
vim -R nginx.conf     # 只读方式打开（安全防护）
```

## 模式

`vim` 经常用的就 3 个模式，外加一个偶尔用的可视模式：

- **普通模式** 按 `esc` 键回到安全模式。任何时候狂按两下 `esc`，都会回到普通模式。
- **编辑模式** 按 `i` 键进入到编辑模式。
- **命令模式** 按 `:` 进入到命令模式，用于执行命令。常用的命令有：
  - `:w` 保存修改
  - `:q` 退出。如果已修改过内容会退出失败。
  - `:q!` 强制退出，解决退出不了的情况。
  - `:wq` 保存并退出。
- **可视模式** 多用于选中内容。把光标移动到想要复制的位置后，按 `v` 进入到可视化模式，移动光标就类似于鼠标的选中内容。

## 光标移动（普通模式）

> tips: 如果要编辑，可以在普通模式下把光标移动到对应的位置后再进入编辑模式会更方便。

- **gg** 跳转到文件第一行，光标处于行首。记忆点：`go go`。
- **G** 跳转到文件最后一行，光标处于行首。记忆点：跟 `gg` 是相反的。
- **^** 跳转到当前行的行首，记忆点：正则的开头符号
- **$** 跳转到当前行的行尾，记忆点：正则的结尾符号
- **上下左右** 使用方向键就好（虽然还有其他的方式）。左右移动时按住 `shift` 键可以按单词移动，会更快一点。

## 增删改查

### 删除

**d** 删除（Delete）。但是 `d` 是一个组合命令，只按 `d` 不生效，它需要指定删除的范围。

- **dd** 删除光标所在位置的一整行。为什么不是 `dl`（Delete line），因为这是最常用的，所以为了方便。
- **dw** 删除从光标位置开始，往后的整个单词。记忆点：Delete Word。
- **dgg** 从光标位置开始，一直删除到文件开始。记忆点：`gg` 是文件第一行。
- **dG** 从光标位置开始，一直删除到文件结尾。记忆点：`G` 是文件最后一行。
- **:2,5d** 删除掉 2~5 行。是的，需要使用到 `命令模式`。
- **像鼠标一样删除** 使用 `可视模式` 选中内容，然后按 `d` 进行删除。

### 复制

**y** 复制（Yank）。但是 `y` 也是一个组合命令，只按 `y` 不生效，它需要指定复制的范围。

- **yy** 复制光标所在的一整行。为什么不是 `yl`（Yank line），理由同 `dd`。
- **yw** 复制从光标位置开始，往后的整个单词。记忆点：Yank Word。
- **ygg** 从光标位置开始，一直复制到文件开始。记忆点：`gg` 是文件第一行。
- **yG** 从光标位置开始，一直复制到文件结尾。记忆点：`G` 是文件最后一行。
- **:2,5y** 复制到 2~5 行。是的，需要使用到 `命令模式`。
- **像鼠标一样复制** 使用 `可视模式` 选中内容，然后按 `y` 进行复制。

### 粘贴

**p**（Put）在光标后面粘贴剪贴板的内容

### 撤回

**u**（Undo）撤消上一步的修改

### 搜索

输入 `/关键字` + `回车` 进入搜索模式。按 `n` 跳转到下一个搜索结果，按 `N` 跳转到上一个搜索结果。
