# Unix Command

这里只放我觉得常用的 `Unix Command`。

---

## 文件与目录管理

### ls [-options] [directory]

> 对应单词：List
> 关于 `ls` 的参数，多数情况下不需要使用。

列出目录内容。默认列出当前目录的文件或者目录，也可以指定对应的目录（`ls [directory]`）。

**常用参数**：

`-l`:
  - 不止展示文件名，还会显示更多的内容：类型、权限、硬链接数、所有者、所属组、字节数、修改时间、名称。
  - 对应单词：long format

`-a`: 
  - 列出的内容包含隐藏文件。
  - 对应单词：all
  - tips: 类 `unix` 系统的 `.`（当前目录） 或者 `..`（上级目录）也是一个隐藏文件，所以你会看到它们俩。

### cd [directory]

> 对应单词：Change Directory

进入到对应的目录。

下面那几项其实是 **特殊路径**:
  - `~` 用户目录
  - `/` 根目录
  - `-` 上一次所在的目录。这个还挺方便的，比如做完了某些操作后，回到之前的目录。

### pwd

> 对应单词：Print Working Directory

显示当前工作目录的绝对路径

### mkdir [...directoryA, directoryB]

> 对应单词：Make Directory

创建目录。是的可以同时创建多个目录（`mkdir aDir bDir`），但是多件多级目录需要使用参数 `-p`。

**常用参数**

`-p`: 
  - 创建多级菜单（`mkdir -p a/b/c`）。
  - 对应单词：Parents

### rm [-options] [...fileA, directoryB]

> 对应单词：remove

删除指定的文件或者目录。

**常用参数**

`-r`: 
  - **非常重要**，要删除目录必加参数。
  - 对应单词：Recursive

`-f`:
  - 强制执行，也比较重要，但是慎重使用。
  - 对应单词：Force

`-v`:
  - 输出删除的文件或者目录名称，如果想知道删除了哪些内容，可以使用。
  - 对应单词：View

`-i`:
  - 交互式删除，如果不确定所有的文件都能删除时，可以通过这个命令来操作。但是需要输入 `yes` or `no` 来确认，当然也可以简写 `y` or `n`来确认。
  - 对应单词：Interactive

tips: 还有个 `rmdir` 的命令，它能用来删除空的目录，如果不是空的目录会报错。相比如 `rm` 会更安全一点，择情使用。

小知识点：为什么命名使用了 `rm`，而不是 `del`？因为当时小型机内存不足，命令解释器（`Shell`）为了节省内存空间，规定命令名不能超过3个字母。

### cp [-options] sourceFile targetFile

> 对应单词：Copy

把指定的文件或目录拷贝一份到指定的地方。

**常用参数**

`-r`:
  - **非常重要**，要赋值目录时必加参数。
  - 对应单词：Recursive

`-i`:
  - 交互式赋值，需要输入 `yes` or `no` 来确认，当然也可以简写 `y` or `n`来确认。
  - 对应单词：Interactive

`-n`:
  - 不覆盖任何已存在的目标文件，**复制目录到已存在的目录时比较常用**。
  - 对应单词：No Clobber

`-f`:
  - 不询问，强制覆盖已存在的文件。**复制目录到已存在的目录时比较常用**
  - 对应单词：Force

`-u`:
  - 仅复制源文件比目标文件新更新的文件或者不存在的文件，**复制目录到已存在的目录时比较常用**
  - 对应单词：Update

### mv [-options] sourceFile filePath/fileName

> 对应单词：Move

移动文件或者目录到指定位置，如果指定了文件名，还会进行重命名。

**常用参数**

`-n`:
  - 不覆盖任何已存在的目标文件，**复制目录到已存在的目录时比较常用**。
  - 对应单词：No Clobber

`-f`:
  - 不询问，强制覆盖已存在的文件。**复制目录到已存在的目录时比较常用**
  - 对应单词：Force

`-u`:
  - 仅复制源文件比目标文件新更新的文件或者不存在的文件，**复制目录到已存在的目录时比较常用**
  - 对应单词：Update

### touch fileName

创建一个空文件，如果文件已存在，更新文件的更新时间。
它多数是用来更新文件的时间，如果需要创建空文件且需要编辑时，不如直接使用 `vim fileName`，不仅能创建新文件，还能直接进入到编辑界面。

## 查看文件内容

### cat

> 对应单词：Catenate。哈哈哈，是的。它并不是🐱的意思，而是链条。

读取文件内容并输出到标准输出。**注意：它不适合读取大文件，因为它会一次性把内容都输出到屏幕上，会导致屏幕疯狂滚动看不清内容、占用大量的 I/O 甚至可能会卡死。**

小知识点：`cat` 的原意是链条，就说明它设计的初衷并不是打印内容，而是用来做文件拼接的。比如：`cat 第一章.txt 第二章.txt 第三章.txt > 全书.txt`。当我们执行 `cat 第一章.txt` 时它依旧在做链条，只不过只有一环，但是 `Unix` 又要求默认输出到屏幕，所以就能打印出内容了。

### less

`less` 是让你可以一屏一屏的阅读内容，而不是想 `cat` 一股脑都展示出来。

和 `cat` 一样，也支持同时查看多个文件（`less 1.txt 2.txt`）。

小知识点：它的名字是因为之前有个工具叫 `more`，`less` 就是加强版的 `more`，之所以叫 `less`，是因为一句话： `less is more`（少即是多）。

**操作建**（只列最常用的）：

- `Space`（空格）：一下屏幕。记忆点：左手拇指直接敲就是下一页。
- `b`：上一屏幕。记忆点：空格的正上方就是往上一页。
- `j`：下一行。记忆点：右手的第一个手指就是下一行。
- `k`：上一行。记忆点：右手的第二个手指就是上一行。
- /xxx：敲回车搜索关键字。`n` 会定位到一个搜索关键字，`p` 会定位到上一个搜索关键字。如果想取消搜索，`less` 是不支持的。但是可以搜索一个不存在的内容，来达到取消搜索的效果。
- 打开多个文件时，`:n` 和 `:p` 可以切换文件。

### head & tail

这两个是分别查看文件的开头和文件的结尾的。会把开头和结尾的内容输出到屏幕上。都是默认打印 `10` 行。

**常用参数**：

-n:
  - 打印的行数
  - 对应的单词是 Lines

**使用场景**：

`head` 多用于查看当前文件的内容是否是我们的目标文件。
`tail` 则多用与查看尾部增加的内容，尤其是实时增加的日志。可以使用 `-f` 进行实时的跟踪。

### wc

> 对应单词：word count

查看文件的数行/词/字节

**常用参数**：

-l:
  - 打印的行数
  - 对应的单词是 Lines

## 搜索

### grep [-options] "matchValue" [targetFile]

> 对应单词：global regular expression print

`grep` 是 `Unix/Linux` 中最核心、最强大的**文本搜索工具**，全称：全局正则表达式打印。它的功能就是：在文件或输入流中，根据指定的“模式（Pattern）”过滤出匹配的行。它不仅仅是找关键词，**它的灵魂在于支持正则表达式**。

tips：如果不指定文件，它会读取标准输入。
