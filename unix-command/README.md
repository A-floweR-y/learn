## 文件与目录管理

### ls [可选参数] [目录]

> 对应英文：List
> 关于 `ls` 的参数，多数情况下不需要使用。

列出目录内容。默认列出当前目录的文件或者目录，也可以指定对应的目录（`ls [目录]`）。

**常用参数**

- **`-l`**（long）：不止展示文件名，还会显示更多的内容：类型、权限、硬链接数、所有者、所属组、字节数、修改时间、名称。
- **`-a`**（all）：列出的内容包含隐藏文件。tips：类 Unix 系统的 `.`（当前目录）或者 `..`（上级目录）也是一个隐藏文件，所以你会看到它们俩。

### cd [目录]

> 对应英文：Change Directory

进入到对应的目录。

下面那几项其实是 **特殊路径**：

- `~`：用户目录
- `/`：根目录
- `-`：上一次所在的目录。这个还挺方便的，比如做完了某些操作后，回到之前的目录。

### pwd

> 对应英文：Print Working Directory

显示当前工作目录的绝对路径

### mkdir [目录…]

> 对应英文：Make Directory

创建目录。是的可以同时创建多个目录（`mkdir aDir bDir`），但是创建多级目录需要使用参数 `-p`。

**常用参数**

- **`-p`**（parents）：创建多级目录（`mkdir -p a/b/c`），中间不存在的父目录也会一起建；目录已存在也不报错。

### rm [可选参数] [文件或目录…]

> 对应英文：Remove

删除指定的文件或者目录。

**常用参数**

- **`-r`**（recursive）：**非常重要**，要删除目录必加参数。
- **`-f`**（force）：强制执行，也比较重要，但是慎重使用。
- **`-v`**（verbose）：输出删除的文件或者目录名称，如果想知道删除了哪些内容，可以使用。
- **`-i`**（interactive）：交互式删除，不确定能不能全删时可以用。确认时输入 `y` 或 `n` 即可。

tips：还有个 `rmdir` 的命令，它能用来删除空的目录，如果不是空的目录会报错。相比如 `rm` 会更安全一点，择情使用。

小知识点：为什么叫 `rm` 不叫 `del`？早期 Unix 图省事，命令名普遍很短。这不是「解释器规定不能超过 3 个字母」——`mkdir`、`chmod` 都超过 3 个字母。

### cp [可选参数] 源 目标

> 对应英文：Copy

把指定的文件或目录拷贝一份到指定的地方。

**常用参数**

- **`-r`**（recursive）：**非常重要**，要复制目录时必加参数。
- **`-i`**（interactive）：交互式复制，确认时输入 `y` 或 `n` 即可。
- **`-n`**（no clobber）：不覆盖任何已存在的目标文件，**复制到已存在的目录时比较常用**。
- **`-f`**（force）：不询问，强制覆盖已存在的文件。**复制到已存在的目录时比较常用**

### mv [可选参数] 源 目标

> 对应英文：Move

移动文件或者目录到指定位置，如果指定了文件名，还会进行重命名。

**常用参数**

- **`-n`**（no clobber）：不覆盖任何已存在的目标文件，**移动到已有同名文件时比较常用**。
- **`-f`**（force）：不询问，强制覆盖已存在的文件。**移动到已有同名文件时比较常用**

### touch [文件]

创建一个空文件，如果文件已存在，更新文件的更新时间。
它多数是用来更新文件的时间，如果需要创建空文件且需要编辑时，不如直接使用 `vim fileName`，不仅能创建新文件，还能直接进入到编辑界面。

## 查看文件内容

### cat [文件…]

> 对应英文：Catenate。哈哈哈，是的。它并不是🐱的意思，而是链条。

读取文件内容并输出到标准输出。**注意：不适合在终端里直接看大文件**，会一口气刷满屏幕、很难读。不一定会把机器卡死；大文件分页看用 `less`，接到管道里用 `cat` 没问题。

小知识点：`cat` 的原意是链条，就说明它设计的初衷并不是打印内容，而是用来做文件拼接的。比如：`cat 第一章.txt 第二章.txt 第三章.txt > 全书.txt`。当我们执行 `cat 第一章.txt` 时它依旧在做链条，只不过只有一环，但是 Unix 又要求默认输出到屏幕，所以就能打印出内容了。

### less [文件…]

`less` 是让你可以一屏一屏的阅读内容，而不是像 `cat` 一股脑都展示出来。

和 `cat` 一样，也支持同时查看多个文件（`less 1.txt 2.txt`）。

小知识点：它的名字是因为之前有个工具叫 `more`，`less` 就是加强版的 `more`，之所以叫 `less`，是因为一句话： `less is more`（少即是多）。

**操作键**（只列最常用的）：

- `Space`（空格）：下一屏幕。记忆点：左手拇指直接敲就是下一页。
- `b`：上一屏幕。记忆点：空格的正上方就是往上一页。
- `j`：下一行。记忆点：右手的第一个手指就是下一行。
- `k`：上一行。记忆点：右手的第二个手指就是上一行。
- `/xxx`：敲回车搜索关键字。`n` 下一个匹配，`N`（大写）上一个匹配。关高亮用 `Esc` 再按 `u`。
- `p`：跳到文件开头（或先输入数字再按 `p`，跳到百分之 N 处）。**不是**上一个搜索匹配。
- 打开多个文件时，`:n` 和 `:p` 切换上/下一个文件。

### head / tail [可选参数] [文件]

这两个是分别查看文件的开头和文件的结尾的。会把开头和结尾的内容输出到屏幕上。都是默认打印 `10` 行。

**常用参数**

- **`-n`**（lines）：打印的行数

**使用场景**

`head` 多用于查看当前文件的内容是否是我们的目标文件。
`tail` 则多用于查看尾部增加的内容，尤其是实时增加的日志。可以使用 `-f` 进行实时的跟踪。

### wc [可选参数] [文件]

> 对应英文：word count

查看文件的行数/词数/字节数

**常用参数**

- **`-l`**（lines）：打印的行数

## 搜索

### grep [可选参数] 模式 [文件或目录]

> 对应英文：global regular expression print

`grep` 是 Unix 中最核心、最强大的**文本搜索工具**，全称：全局正则表达式打印。它的功能就是：在文件或输入流中，根据指定的“模式（Pattern）”过滤出匹配的行。它不仅仅是找关键词，**它的灵魂在于支持正则表达式**。

说明：**它用来搜索文件内容的。不能用来搜索文件**。搜索文件是 `find` 命令的工作。

tips：如果不指定文件，它会读取标准输入。

**搜索文件**

```bash
grep "xxx" xxx.txt
```

**搜索输入流**

```bash
cat xxx.txt | grep "xxx"
```

**常用参数**

- **`-r`**（recursive）：**非常重要**，搜索目录必加参数。
- **`-l`**（files with match）：**非常重要**，只列出匹配到内容的文件名。
- **`-i`**（ignore-case）：忽略大小写
- **`-w`**（word-regexp）：匹配整个单词。比如搜 `log` 时不会匹配到 `login` 或 `catalog`。
- **`-v`**（invert）：反向匹配，就是排除输入的匹配项
- **`-n`**（line number）：搜索某个具体的文件时，展示所有匹配内容的行号
- **`-c`**（count）：只展示匹配的行数，不展示匹配到的内容。支持搜索文件夹，会展示所有文件匹配到的行数，没匹配到的文件会展示 `0`。

**重要说明**

即使我们输入的是字符，默认也是按**基础正则**来匹配的（功能没有扩展正则那么全，但 `.` 仍然是任意字符）。所以要写更接近编程习惯的正则，用 `-E`。比如匹配 IP（*127.1.1.1*），不能直接 `grep "127.1.1.1"`，需要 `grep "127\.1\.1\.1"`，或者用 `-F` 按纯文本匹配：`grep -F "127.1.1.1"`。

- **`-E`**（extended）：**需要了解**。扩展正则，更接近常见编程正则。
- **`-F`**（fixed strings）：**需要了解**。放弃正则特殊含义，按字面量匹配。字面量搜索优先用这个。

以前还有 `egrep`、`fgrep`，分别相当于 `grep -E`、`grep -F`。现在就是别名，有的系统已标过时，直接写 `grep -E` / `grep -F` 即可。

### find [搜索路径] [匹配条件] [处理动作]

说明：

- `搜索路径`：从哪里开始找（如 `.` 当前目录，`/` 根目录）。不指定路径默认是当前目录。
- `匹配条件`：定义要找什么样的文件。带 `*`、`?` 的条件要加引号，免得被 shell 先展开，例如 `-name "*.txt"`。`-type f`、`-mtime +30` 这类不必加引号。文件名通配常用 `*`、`?`、`[]`（`>` 是重定向，不是 find 的通配符）。
- `处理动作`：找到后干什么（默认动作是 `-print`，即打印路径）。

**常用参数**

- **`-name`**：文件名区分大小写。与之对应的就是 `-iname` 忽略文件名称大小写。
- **`-regex`**：用正则匹配**完整路径**（不是只匹配文件名）。例如一位数字的 txt：`find . -regex ".*/[0-9]\.txt"`。`-iregex` 是忽略大小写的 `-regex`。
- **`-type`**：按类型区分搜索
  - `-type f` 文件
  - `-type d` 目录
- **`-size`**：按大小搜索。`c` 字节，`k` KB，`M` MB，`G` GB。`+` 是大于，`-` 是小于。例如：`find . -size -1k`（小于1KB）
- **`-mtime`**：按修改时间搜索（天为单位）。`+` 超过（更老），`-` 不足（更新）。例如：`find . -mtime +30`（超过 30 天没改过的）；`-mtime -30` 是 30 天内改过的。
- **`-amin`**：按访问时间搜索（分钟为单位）。`+` 是大于，`-` 是小于。例如：`find . -amin -5`（5分钟内被访问过）

**处理动作**

- **`-exec`**：对找到的文件执行某些操作，比如：`find . -name "*.sh" -exec chmod +x {} \;`。还有一个更安全的 `-ok`，每次都会询问你。
- **`-delete`**：直接删除找到的文件。**请确认清楚使用**。

### which [命令]

返回某个命令在 `PATH` 里的绝对路径。zsh 下对 shell 内置命令常会显示 `shell built-in command`；bash 里外部的 `which` 往往看不到内置命令。要判断是内置还是外部程序，用 `type` 更靠谱。

## 压缩、打包

### tar [可选参数]

> 对应英文：tape archive

`tar` 是一个打包工具，只负责打包不负责压缩。压缩一般都是指定其他工具，比如 `gzip`。

**常用参数**

- **`-v`**（verbose）：显示过程。**建议每次都加上**，这样可以看到进度。
- **`-f`**（file）：指定文件名。**建议每次都加上**，毕竟每次都要指定文件名
- **`-c`**（create）：创建归档（打包）。要压缩再加 `-z` 等。
- **`-x`**（extract）：解开归档。
- **`-z`**：使用 `gzip` 压缩或解压。当然也支持其他的压缩方式，多数情况就直接选择这个就好。

**使用示例**

```bash
# 在本机或 CI 环境打包
tar -zcvf dist.tar.gz dist/

# 在服务器解压到当前目录（会生成 ./dist 文件夹）
tar -zxvf dist.tar.gz

# 在服务器解压到其他目录（比如 /var/www/html）
tar -zxvf dist.tar.gz -C /var/www/html
```

当天还有 `gzip` 和 `zip` 等命令，但是我觉得没有使用场景，用的时候再查吧！

## 进程、端口

### lsof [可选参数]

> 对应英文：List Open Files

在 Linux 哲学里，“一切皆文件”（包括网络连接、管道、设备等）。`lsof` 就是专门来查看是谁占用了这个资源。

**常用参数**

- **`-i`**：最常用，查看谁占用了端口 `lsof -i:端口号`。其中 `PID` 是最重要的，`COMMAND` 查看程序名称。输出结果如下。

```bash
COMMAND   PID   USER   FD   TYPE  DEVICE    SIZE/OFF  NODE          NAME
node      12345 root   22u  IPv4  XXXXX     0t0       TCP *:3000    (LISTEN)
```

### kill [进程号]

找到谁占用了，要杀死这个进程：`kill PID`。
但是有一点需要清楚，`kill PID`只是通知这个进程要赶紧退出。但是，如果这时候这个进程本身就卡死了，就需要用 `kill -9 PID` 来强制杀死进程。如果可以，尽可能不用强制杀死进程。

### ps

> 对应英文：Process Status

进程快照状态，把所有正在运行的进程（程序）给你列出来。快照是静态的，要查看动态的，需要使用 `top`。
命令不需要记，多数情况都是固定的：`ps aux` 全部查看。
一般要配合 grep 来筛选出对应的进程。比如：`ps aux | grep "node"`。

## 网络

### ssh 用户@地址

> 对应英文：Secure Shell（安全外壳协议）

连接自己的远程服务器（`ssh root@你的服务器IP`）。如果端口被改过（比如 2222），那就是：`ssh -p 2222 root@你的服务器IP`。默认端口是 `22`.

当然每次登录都输入 IP 地址和密码都比较费事，可以在本地生成一个专门的 `ssh-key`：

```bash
# -t 指定加密算法 ed25519 首选，rsa 有点老了
# -f 指定文件名称
# -C 备注内容
ssh-keygen -t ed25519 -f ~/.ssh/my_server -C "my server"
```

然后再 `~/.ssh/config` **文件**里创建一个快捷登录的别名。内容如下：
```bash
Host myserver
  HostName 你的服务器IP
  User root
  Port 2222
  IdentityFile ~/.ssh/my_server
  IdentitiesOnly yes
```

使用 `ssh-copy-id` 把**公钥**拷到服务器的 `authorized_keys`：`ssh-copy-id -i ~/.ssh/my_server.pub myserver`。这一次可能要输入密码，之后用密钥登录，直接：`ssh myserver` 即可。

### scp [可选参数] 源路径 目标路径

> 对应英文：Secure Copy（安全复制）

使用 SSH 协议，把本地文件拷贝到指定的服务器上，或者从服务器下载到本地。

**上传文件/目录**

上传整个目录需要 `-r`。

```bash
scp 文件 root@IP地址:目录地址
scp -r 目录 root@IP地址:目录地址
```

**下载文件/目录**

下载整个目录同样需要 `-r`。

```bash
scp root@IP地址:目录地址 文件地址
scp -r root@IP地址:目录地址 文件地址
```

配好 `~/.ssh/config` 之后，`scp` 也能用那个别名（它走 SSH）：

```bash
scp dist.tar.gz myserver:/var/www/html/
```

若还想再短，可以在 `~/.zshrc` 里加 alias：`alias deploy='scp dist.tar.gz myserver:/var/www/html/'`

### ping [可选参数] 地址

> 对应英文：Packet Internet Groper（互联网包探测工具）

这个就太常用了，看看地址通不通（ICMP）。直接：`ping hostname`。名字来自声呐的 ping；Packet Internet Groper 是后人编的全称。

**常用参数**

- **`-c`**（count）：`ping` 多少次。结束时会给一个统计数据。包含：丢包率、最小/平均/最大时长。
- **`-i`**（interval）：每次 `ping` 的时间间隔，默认 1 秒钟。

### curl [可选参数] URL

> 对应英文：Client URL

多数情况下用来补 ping 够不到的那一层：ping 通只说明 ICMP 通，`curl` 才能看 HTTP(S) 是否正常。

**常用参数**

- **`-i`**（include）：把响应头一并打出来
- **`-v`**（verbose）：查看更详细的各个节点握手过程

### exit

退出当前 shell。在 SSH 会话里，等于断开远程连接。

## 符号

**符号非常重要**，尤其是多个命令组合在一起的时候。

### 管道

`|`：把左边输出变成右边输入。比如：`ps aux | grep node`。

### 重定向

`>`：覆盖写入。文件里旧内容全没了，只有新内容。
`>>`：追加写入。旧内容保留，新内容接在末尾。

### 逻辑短路

`&&`：**与**，前一个成功了，才执行后一个。
`||`：**或**，前一个失败了，才执行后一个。

### 快捷路径

`*`：通配符号。
`~`：用户目录。
`/`：根目录。

## 系统信息

### echo [内容]

给它什么，它就把什么打印到屏幕上。**回声** 这个名字起的挺好。**比较常用**。

### date

查看当前这台机器的时间（SSH 上去再执行，才是服务器时间）。

### export 变量名称=变量内容

设置环境变量，对**当前 shell 和它拉起的子进程**有效。关掉终端就没了；要长期生效写进 `~/.zshrc`。**比较常用**。

### clear

清空屏幕，方便查看内容。
