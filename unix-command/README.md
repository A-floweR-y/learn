# Unix Command

这里只放我觉得常用的 `Unix Command`。

---

## 文件与目录管理

### ls [-options] [directory]

> 对应单词：List
> 关于 `ls` 的参数，多数情况下不需要使用。

列出目录内容。默认列出当前目录的文件或者文件夹，也可以指定对应的目录（`ls [directory]`）。

**常用参数**：

`-l`:
  - 不止展示文件名，还会显示更多的内容：类型、权限、硬链接数、所有者、所属组、字节数、修改时间、名称。
  - 对应单词：long format

`-a`: 
  - 列出的内容包含隐藏文件。
  - 对应单词：all
  - tips: 类 `unix` 系统的 `.`（当前目录） 或者 `..`（上级目录）也是一个隐藏文件，所以你会看到它们俩。

### cd [directory]

> 对应单词：Change Directory

进入到对应的目录。

下面那几项其实是 **特殊路径**:
  - `~` 用户目录
  - `/` 根目录
  - `-` 上一次所在的目录。这个还挺方便的，比如做完了某些操作后，回到之前的目录。

### pwd

> 对应单词：Print Working Directory

显示当前工作目录的绝对路径

### mkdir [directory a, directory b]

> 对应单词：Make Directory

创建文件夹。是的可以同时创建多个文件夹（`mkdir aDir bDir`），但是多件多级文件夹需要使用参数 `-p`。

**常用参数**

`-p`: 
  - 创建多级菜单（`mkdir -p a/b/c`）。
  - 对应单词：Parents

### rm [-options] [file A, dir B]

> 对应单词：remove

删除指定的文件或者文件夹。

**常用参数**

`-r`: 
  - **非常重要**，要删除文件夹必加参数。
  - 对应单词：Recursive

`-f`:
  - 强制执行，也比较重要，但是慎重使用。
  - 对应单词：Force

`-v`:
  - 输出删除的文件或者目录名称，如果想知道删除了哪些内容，可以使用。
  - 对应单词：View

tips: 还有个 `rmdir` 的命令，它能用来删除空的文件夹，如果不是空的文件夹会报错。相比如 `rm` 会更安全一点，择情使用。

小知识点：为什么命名使用了 `rm`，而不是 `del`？因为当时小型机内存不足，命令解释器（`Shell`）为了节省内存空间，规定命令名不能超过3个字母。
