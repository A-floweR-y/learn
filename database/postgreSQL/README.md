# PostgreSQL

PostgreSQL 的基本结构分为：Database、Schema 和 Table。

- Database：数据库。是一个相对独立的数据组织空间。
- Schema：逻辑命名空间。有点类似于目录用来存放不同的表。比如设置为：public、order、audit 等。
- Table：数据表。用于组织和保存结构化业务数据的对象。有点像 Excel 表格，分为列、行。例如一个 user 表：

|id|username|email|
|--|--|--|
|1|Tom|tom@example.com|
|2|Jack|jack@example.com|
